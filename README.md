# MediTrack (File-Based)

> File-based medical record tracking system for patient data management and appointment scheduling.

![status](https://img.shields.io/badge/status-prototype-yellow) ![license](https://img.shields.io/badge/license-MIT-blue) ![stack](https://img.shields.io/badge/stack-Python-green)

## 📖 About
A lightweight, file-based medical records tracker built in Python. Designed as a CLI application for small clinics that need basic patient data management without the overhead of a full database system.

## ✨ Features
- Patient record CRUD operations
- File-based persistent storage (JSON/CSV)
- Appointment scheduling
- Basic data search and filtering

## 🛠 Tech Stack
- **Language**: Python 3.x
- **Storage**: File-based (JSON/CSV)

## 🚀 Quick Start
```bash
git clone https://github.com/ayushjhaa1187-spec/meditrack_file_based.py.git
cd meditrack_file_based.py
python meditrack.py
```
